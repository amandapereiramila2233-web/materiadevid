## Descrição
Programa em Python para registro de pedidos de uma lanchonete.

## Funcionalidades
- Leitura do nome do cliente
- Cardápio com 5 produtos
- Escolha por código e quantidade
- Cálculo de subtotal e valor total
- Desconto: 5% para R$ 50 a R$ 99,99 e 10% para R$ 100 ou mais
- Escolha de forma de pagamento
- Validação de entradas incorretas
- Exibição de resumo final

2. Executar no terminal: python lanchonete.py
